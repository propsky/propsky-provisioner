## 5. 失敗與恢復測試

每項測試完成後，記錄實際錯誤訊息與 log 檔名。

### 5.1 COM port 佔用

- [ ] 讓其他程式佔用 COM port
- [ ] 按「開始」
- [ ] UI 顯示 COM port 被佔用或無法開啟
- [ ] 關閉其他程式後可重新開始

### 5.2 WiFi 失敗

- [ ] 暫時輸入錯誤 WiFi 設定
- [ ] 等待開機驗收逾時
- [ ] UI 顯示 FAIL
- [ ] CSV/XLSX 結果更新為 `FAIL`
- [ ] FAIL 原因寫入備註與 `logs/`

### 5.3 SHA-256 失敗

- [ ] 模擬一個檔案驗證不符
- [ ] 工具會重傳一次
- [ ] 第二次仍不符時流程 FAIL
- [ ] 沒有誤顯示 PASS

### 5.4 raw REPL 失敗

- [ ] 模擬板子無法進入 raw REPL
- [ ] 工具會依規格重試最多 3 次
- [ ] 仍失敗時會自動 erase/write flash
- [ ] 重燒後自動回到連線流程
- [ ] 重燒後仍失敗時顯示 FAIL，沒有無限重試

## 測試注意事項

- 不要把含有 WiFi 密碼的 `config.ini`、`wifi.dat` 或其他私人設定檔上傳到 GitHub。
- raw-paste 尚未實作，大檔上傳請特別觀察是否有 timeout 或檔案驗證失敗。
- MQTT 目前在開機 log 視窗內判定；若韌體很晚才輸出 MQTT 狀態，請在回報中註明。
- 任一片發生 token/MAC 不一致、帳本覆蓋、或板子進 bootloader，先停止四路並行測試並保留完整 log。
